# JavaScript

Colección de ejercicios y proyectos desarrollados con **JavaScript** para practicar lógica de programación y manipulación del DOM.

## Estructura

- `01-tipos/` → Tipos de datos y variables.
- `02-operadores/` → Operadores y expresiones.
- `03-control-flujo/` → Condicionales y estructuras de control.
- `04-ejercicios/` → Ejercicios prácticos de lógica.
- `05-objetos/` → Objetos y métodos en JavaScript.
- `06-segundo-curso/` → Temas y prácticas avanzadas.
- `calculadora/` → Proyecto de calculadora funcional.
- `index.html` → Página principal de acceso.

## Objetivo

Reforzar fundamentos de JavaScript mediante ejercicios prácticos y pequeños proyectos interactivos.
