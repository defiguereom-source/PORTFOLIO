# React

Colección de proyectos desarrollados con **React** para practicar componentes, estado y manejo de hooks.

## Estructura

- `01-basico_react/` → Introducción a React y creación de componentes básicos.
- `02-contador_clicks/` → Proyecto de contador utilizando estado.
- `03-calculadora/` → Calculadora funcional con componentes.
- `04-to_do/` → Aplicación de lista de tareas con React.
- `05-componentes_clases/` → Práctica con componentes basados en clases.
- `06-cafeteria/` → Proyecto de página web de cafetería en React.


## Objetivo

Aprender los fundamentos de React, incluyendo componentes, estado, props y manejo de eventos mediante proyectos prácticos.
