# TypeScript

Colección de ejercicios y proyectos desarrollados con **TypeScript** para practicar tipado estático y mejora de la calidad del código.

## Estructura

- `basico/` → Ejercicios básicos para aprender sintaxis y tipos en TypeScript.
- `To_Do/` → Aplicación de lista de tareas desarrollada con TypeScript.

## Objetivo

Practicar el uso de TypeScript en proyectos pequeños, reforzando tipado, estructuras de datos y desarrollo de aplicaciones interactivas.
