# DOM

Ejercicio y proyecto enfocado en la manipulación del **DOM (Document Object Model)** usando **JavaScript**.

## Contenido

- Manipulación de elementos HTML.
- Eventos y listeners.
- Creación y modificación dinámica de contenido.
- Interacción con formularios y componentes.

## Objetivo

Practicar la interacción entre JavaScript y el DOM para crear páginas web dinámicas e interactivas.
