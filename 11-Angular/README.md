# Angular

Colección de proyectos desarrollados con **Angular** para practicar componentes, servicios y estructura de aplicaciones SPA.

## Estructura

- `00-angular-17-app/` → Introducción y configuración básica de Angular 17.
- `01-cafeteria/` → Proyecto de página web de cafetería desarrollado con Angular.
- `angular-17-app/` → Aplicación base para prácticas generales con Angular 17.

## Objetivo

Aprender los fundamentos de Angular mediante proyectos prácticos, trabajando con componentes, routing y estructura de aplicaciones modernas.
