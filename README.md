# Conceptos básicos de Frontend

## ¿Qué es el desarrollo Frontend?

El desarrollo frontend es la parte visual e interactiva de una aplicación web.  
Se encarga de todo lo que el usuario puede ver y utilizar directamente desde el navegador.

---

##  Tecnologías principales

### 🔸 HTML
Estructura el contenido de una página web.

- Títulos
- Formularios
- Botones
- Imágenes
- Enlaces

---

### 🎨 CSS
Se utiliza para diseñar y dar estilos a la interfaz.

- Colores
- Espaciados
- Animaciones
- Diseño responsivo
- Flexbox y Grid

---

### ⚡ JavaScript
Permite agregar interactividad y lógica del lado del cliente.

- Eventos
- Manipulación del DOM
- Consumo de APIs
- Validaciones
- Funcionalidades dinámicas

---

### 🟦 TypeScript
Superset de JavaScript que agrega tipado estático y mejor organización del código.

---

### 🅰️ Angular
Framework frontend para crear aplicaciones web modernas y escalables.

---

## 📱 Diseño Responsivo

El diseño responsivo permite que una aplicación se adapte correctamente a diferentes dispositivos:

-  Computadoras
-  Celulares
-  Tablets

Herramientas utilizadas:

- Media Queries
- Flexbox
- CSS Grid
- Unidades relativas
